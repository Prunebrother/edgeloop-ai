# OpenMP runtime corresponding source

Ollama's official Linux archive contains libgomp.so.1.0.0 (SHA-256 e985bcbb6b444c2c472de70c331ab101e6de860affa3a20d1d1aecd06d9242e8). It matches byte-for-byte the library in AlmaLinux libgomp-8.5.0-28.el8_10.alma.1.x86_64.rpm, obtained from https://repo.almalinux.org/almalinux/8/BaseOS/x86_64/os/Packages/.

The GCC/OpenMP corresponding-source export, including distribution patches and build instructions, is included at third-party-sources/gcc-8.5.0-28.el8_10.alma.1-openmp-source.tar.gz. It preserves all GCC source files, OpenMP build sources, recipes, patches and notices except one unrelated binary Go ELF test core containing captured credential environment data. The export is explicitly marked as modified in PRIVACY-SOURCE-EXPORT.md and SOURCE-EXPORT.json; it is not a signed RPM. The original input RPM was obtained from https://vault.almalinux.org/8.10/BaseOS/Source/Packages/gcc-8.5.0-28.el8_10.alma.1.src.rpm. The source hash is pinned in release-inputs.json. GPL-3.0.txt and GCC-RUNTIME-LIBRARY-EXCEPTION.txt retain the library's license terms. No changes were made to the distributed library.

The original input hash and the exact export hash are pinned in release-inputs.json. The optional Go ELF test requiring the omitted core fixture is unavailable; the source and build inputs for the shipped OpenMP library are unchanged. No copyright, license or attribution notice was removed.
