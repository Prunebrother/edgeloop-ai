# F2.10.1 release privacy remediation

Runtime bytecode is regenerated with the bundled Python version, checked-hash invalidation and canonical relative code filenames. The installer protects sealed files against automatic cache writes. Every seal, including pack-only, regenerates and checks caches before creating the manifest.

The OpenMP corresponding-source container is an explicitly documented export of the pinned original RPM. It omits one unrelated binary Go test core containing captured credential environment data. The remaining GCC source, OpenMP build inputs, distribution patches, recipes and notices are preserved without content changes. The signed RPM is not modified or presented as the export. The transform is reproducible through tools/export-openmp-source.py and its output hash is pinned.

No model weights, model registration, character definitions, templates or portraits are changed. Portrait provenance and truthful project/upstream attribution remain intact. Machine-specific audit evidence and account details remain private. No replacement authorship is invented.

The rebuilt split bundle, source archive and installer are verified as actual distribution files. Mocked tests do not establish real inference, GPU behavior or physical hardware behavior. A versioned release requires explicit user authorization; no build command publishes automatically.
