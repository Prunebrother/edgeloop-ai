# Models and artwork

The complete Linux Release bundles both original base-model weight sets and ten prepared character models. Base layers are stored once and shared between character aliases. Source Modelfiles, lore and personality text are preserved unchanged. No private developer aliases or model-store history are exported. The earlier Mira prompt fragment has no FROM/base model; it remains source-only and is not advertised as an installable companion.

All 72 referenced portraits (12 expressions each for Evelyn, Daisy, Celeste, Nova, Mira and VEX-9) are included. VEX-9 (added 2026-11-17) is new art generated by the maintainer with the same local Krea 2 model as the menu art (Krea Noct V4 with the Krea 2 Identity Edit LoRA, Krea 2 Community License): a locked concept design, twelve full-body expressions over a still lab background, each image and clip reviewed and approved by hand; her portraits are likewise the first frame of each idle clip. Since 2026-11-16 each portrait is the first frame of its idle clip: the original art with the figure cut out and placed over a still background plate (PA-1), so poses, faces and style are unchanged but the files are no longer byte-identical to the original generations. On 2026-10-29 the maintainer confirmed that the art was generated by the project and authorized its inclusion in the release. Only manifest-referenced images are published; unrelated reference images/collages remain outside the package. Source and artwork use the project's AGPL-3.0-only distribution terms.

Menu art (`src/assets/menu`, added 2026-11-16): the main menu backdrop, the Asterion key art and four chapter images are new images generated by the maintainer with a local Krea 2 model (Krea Noct V4, a Krea 2 Turbo merge, under the Krea 2 Community License, which leaves ownership of generated images with their maker); they show no people. They are AI-generated, and every image was reviewed by hand before inclusion. The companion figures and face crops are cut out of the portraits above (no new depiction). The logo mark is a hand-written SVG; the wordmark is "EDGELOOP" set in Unbounded ExtraBold and converted to outlines (SIL Open Font License, licenses/UNBOUNDED-OFL.txt). Story titles use Cormorant Garamond SemiBold, a Latin subset in WOFF2 (SIL Open Font License, licenses/CORMORANT-GARAMOND-OFL.txt).

The bundled Ollama runtime is 0.40.13. Exact runtime inputs and base-weight SHA-256 digests are recorded in `release-inputs.json`; `BUNDLE.json` in the release records every bundled file hash. The Apache-2.0 model license layers are retained in the model store and copied to `licenses/models/`. Ollama, Python and library notices are retained separately; see THIRD_PARTY_NOTICES.md. The weight tensors are not modified; character aliases add the public Modelfile parameters/prompts.

For source developers using a separate existing Ollama, manual installation remains available:

```bash
OLLAMA_HOST=127.0.0.1:11435 ollama pull huihui_ai/qwen3.5-abliterated:9b
OLLAMA_HOST=127.0.0.1:11435 ollama create nova-narrative-v1 -f characters/models/nova-narrative-v1/Modelfile
```

Use the matching source path and intended alias for another character. The original `evelyn` and `daisy` definitions use `qwen3:8b`. Do not overwrite an unrelated existing alias. The complete installer handles these steps in its own model store; end users do not need these commands.

Local inference performance and model behavior depend on hardware and context. The abliterated model has reduced filtering; retain the publisher's usage notes. Automated/mock tests cannot establish conversational quality or physical safety.
